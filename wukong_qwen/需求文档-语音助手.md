# DeepSeek智能语音助手需求文档

## 项目概述

DeepSeek智能语音助手是一款基于悟空机器人和DeepSeek V3 API开发的语音交互助手系统。它能够通过语音识别用户的问题，并利用DeepSeek V3大语言模型提供智能回答，通过悟空机器人的语音合成功能播放响应。

## 功能需求

### 1. 语音交互

#### 1.1 语音输入
- 系统能够持续监听用户的语音输入
- 支持两种工作模式：
  - **唤醒词模式**：需要用户先说特定唤醒词（如"deepseek"）才开始处理后续指令
  - **无唤醒词模式**：直接识别完整句子并处理，无需唤醒词

#### 1.2 语音识别处理规则
- 必须识别到相对完整的句子才进行处理（不处理单个词或不完整片段）
- 当系统正在处理一个请求时，不响应新的语音输入（避免重复触发）
- 处理语音请求时，给予用户明确的反馈（如"我想想"），提示系统正在处理

#### 1.3 语音输出
- 使用悟空机器人的TTS（文本转语音）功能播放DeepSeek生成的回答
- TTS播放时避免自我语音识别，防止系统识别自己的声音作为新指令

### 2. 智能对话

#### 2.1 对话能力
- 集成DeepSeek V3 API，提供智能、自然的对话响应
- 根据语音输入的完整内容生成相关答案
- 支持多种日常信息查询、闲聊和任务辅助

#### 2.2 对话管理
- 处理过程中提供中间状态反馈（"我想想"）
- 维护对话上下文，支持多轮对话
- 错误处理和恢复机制，在API调用失败时提供友好提示

### 3. 系统控制

#### 3.1 配置灵活性
- 通过配置文件(.env)控制系统行为
- 支持设置唤醒词或无唤醒词模式（WAKE_WORD=""表示无唤醒词模式）
- 可配置TTS等待反馈（ENABLE_THINKING_FEEDBACK=true）

#### 3.2 资源管理
- 合理管理网络请求和响应，优化API调用
- 动态调整语音识别轮询间隔，减少资源占用
- 完善的日志系统，方便问题诊断和性能监控

## 技术需求

### 1. 硬件要求
- 悟空机器人Mini或其他支持的型号
- 网络连接用于DeepSeek API访问

### 2. 软件要求
- Python 3.6+运行环境
- 悟空机器人SDK
- DeepSeek API访问密钥
- aiohttp用于异步API调用
- python-dotenv用于环境变量管理

## 性能需求

- 语音识别响应时间：2秒内
- DeepSeek API平均响应时间：5秒内
- 系统稳定运行时间：>24小时无需重启
- 内存占用：<200MB

## 优先级和阶段划分

### 第一阶段（核心功能）
- 实现基本语音识别和TTS功能
- 集成DeepSeek V3 API
- 支持无唤醒词模式
- 实现"我想想"的处理反馈

### 第二阶段（功能完善）
- 优化语音识别的完整句子判断
- 改进TTS播放功能和音质
- 完善对话历史管理
- 增强错误处理机制

### 第三阶段（体验优化）
- 增加更多自定义配置选项
- 优化资源使用和性能
- 增加更多交互功能和场景支持

## 验收标准

- 能够在无唤醒词模式下准确识别完整句子并响应
- 处理请求时显示"我想想"的反馈
- TTS功能正常工作，语音播放清晰可辨
- 在处理过程中不响应新的语音输入
- 系统能够稳定运行，不出现崩溃或资源泄漏
- 配置项生效，可通过配置文件调整系统行为
